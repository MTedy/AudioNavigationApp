# Nawigacja Audio dla osób niewidomych - Wersja 0.1

Aktualna wersja zawiera fundamenty architektury wieloprojektowej oraz w pełni zaimplementowaną matematykę ruchu gracza w środowisku 2D/3D (przygotowanie pod silnik OpenAL).

## Jak uruchomić?
Aby uruchomić aplikację bez otwierania Visual Studio, kliknij dwukrotnie plik `Uruchom_Radar.bat`. 
Wymagane jest zainstalowane środowisko .NET 8.0 (lub nowsze) SDK.

## Sterowanie
* **W / S** - Krok w przód / w tył (względem aktualnego kierunku patrzenia)
* **A / D** - Krok w lewo / w prawo
* **Q / E** - Obrót (zmiana wektora kierunku)
